# Online Car Store

Welcome to the **Online Car Store**. This is a website project where users can explore a catalog of cars, view their detailed specifications, and learn more about the store. The site has a clean and easy-to-use interface for browsing cars and learning more about each one.

## Features
- **Home page** with a list of cars in stock.
- **Product pages** with complete details about each vehicle (make, model, year, price, technical specifications).
- **About Us page** with information about the store.

## Technologies Used
- **HTML**: Structure of the website content.
- **CSS**: Styles for the presentation and design of the site.
